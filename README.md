# Lumivara Online Client

โปรแกรมสำหรับเล่น Lumivara Online บน Windows 64-bit พร้อมโหมด Picture-in-Picture และคีย์ลัดควบคุมหน้าต่าง

## ดาวน์โหลด

**[ดาวน์โหลดโปรแกรมได้ที่หน้า Releases](https://github.com/newkiss2582/Lumivara-Online-Client/releases)**

เปิดรุ่นที่ต้องการ แล้วเลือกไฟล์ดาวน์โหลดในส่วน **Assets**

- **Setup (.exe):** เปิดตัวติดตั้ง เลือกโฟลเดอร์ แล้วติดตั้ง โปรแกรมจะสร้าง Shortcut บนเดสก์ท็อปให้
- **แบบ ZIP (ถ้ามีในรุ่นนั้น):** แตกไฟล์ทั้งชุด แล้วเปิด `Lumivara Online.exe` ได้เลย

## คีย์ลัด

| ปุ่ม | การใช้งาน |
|---|---|
| F5 | รีเฟรชเกม |
| Ctrl+Shift+P | สลับ PiP / จอปกติ |
| F11 / Alt+Enter | สลับเต็มหน้าจอ |
| Esc | ออกจากเต็มหน้าจอหรือกลับจาก PiP |
| F1 | เปิด / ปิดวิธีใช้ |
| F8 | ซ่อนเกมและปิดเสียง |
| Ctrl+Shift+H | ซ่อน / เรียกเกมกลับ |

ดับเบิลคลิกไอคอนเกมในถาดระบบเพื่อเรียกกลับได้เช่นกัน

## หมายเหตุ

- ต้องใช้อินเทอร์เน็ตเพื่อเชื่อมต่อเกม
